Fitness Level Prediction

Project Overview

This project focuses on analyzing fitness and health-related data using Python and Machine Learning techniques.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

Project Features

- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Data Visualization
- Fitness Level Prediction
- Decision Tree Classification
- K-Means Clustering
- PCA (Principal Component Analysis)

Objective

The main objective of this project is to analyze fitness data and build machine learning models to understand and predict fitness levels.
